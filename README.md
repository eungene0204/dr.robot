# Dr.Robot

PC 매장 상담 도구. 한국어 요청 입력 → 실제 부품 데이터로 견적 비교 → 규칙 검증 → 확인된 구성의 견적서 발행을 제공합니다.

## 시작

Node.js 24+, Python 3이 필요합니다.

```sh
npm install
npm run pipeline
npm run dev
```

기본적으로 `public/data/catalog.json`의 **실제 데이터**를 읽습니다. API가 있으면 `/api/catalog`를 먼저 사용하며 정적 스냅샷으로도 같은 추천 엔진을 실행합니다. 연결 실패 시 가상값으로 돌아가지 않습니다. 가상 시연은 명시적으로 `?demo=1`을 붙일 때만 열립니다.

로컬 API를 별도 터미널에서 실행하려면:

```sh
cp .env.example .env
node --env-file=.env backend/server.mjs
```

Vite는 `/api`를 8000 포트로 프록시합니다. 서버는 127.0.0.1에만 바인딩합니다. 키가 없으면 로컬 요구 분석을 사용하고, `OPENROUTER_API_KEY`와 `OPENROUTER_MODEL`을 설정하면 요구 구조화·최대 3개 확인 질문·스키마 검증·재시도·사용량 로그를 사용합니다.

## 실제 데이터

첫 수집: 실제 상품 23개(전체 9개 부품 카테고리), CPU/GPU 8개 칩 모델의 Blender 실측. 상품별 판매 SKU·가격·출처·수집 시각·원문 해시와 벤치마크 버전·표본 수를 저장합니다.

- 가격/스펙: 다나와 공개 상품 JSON-LD. 상품 코드 고정 매핑, KRW·가격·SKU 검증.
- 벤치마크: CC0인 Blender 공식 스냅샷의 단일 장치·동일 버전·3장면 제출 중앙값.
- 네이버 쇼핑 공식 API를 통한 가격 교차 검증은 키와 검수된 상품 ID 매핑을 설정하면 사용할 수 있습니다.
- 가격 24시간, 벤치마크 스냅샷 45일 경과 시 추천에서 제외합니다.
- 이상 가격은 격리하고 직전 정상값을 유지합니다. 실패했다고 기준 시각을 갱신하지 않습니다.
- CPU/GPU 외에는 가짜 종합 성능 점수를 만들지 않습니다. 실제 용량·규격·공개 속도를 비교합니다.

**Blender 지수는 게임 FPS나 AI 추론 속도가 아닙니다. 가격비교 최저가는 배송비·실재고가 확인된 주문금액이 아닙니다. 제조사 BIOS·실물 간섭 등 미확인 항목이 있으면 최종 발행을 차단합니다.**

전체 소스, 검수, 스케줄, 확장 방법은 [데이터 파이프라인 운영 문서](pipeline/README.md)를 참고하세요.

## 주요 명령

```sh
npm run pipeline                     # 가격 + 벤치마크 수집
npm run pipeline:prices              # 가격·스펙
npm run pipeline:benchmarks          # 벤치마크
npm run pipeline:discover -- 모델명   # 신제품 후보 검색 (자동 승인하지 않음)
npm run pipeline:schedule            # Asia/Seoul 09:00 / 18:00
npm test
npm run build
```

스케줄러는 실행 중인 서버/컴퓨터에서 동작합니다. **Sites의 정적 배포본은 마지막 배포 시점의 스냅샷입니다.** 로컬 수집 결과를 호스팅 URL에 반영하려면 재배포하거나 상시 운영 API/인증된 데이터 업로드 경로가 필요합니다. 현재 배포는 영구 서버나 클라우드 수집 작업을 자동으로 설치하지 않습니다.

## 화면 및 API

상담 입력, 3안 비교, 부품 교체, 미확인 항목을 구분하는 호환성 보고서, 데이터 관리, 실제 부품 라이브러리, 브라우저 상담 이력, 매장 설정, 인쇄/PDF 저장, 같은 스냅샷 기준 공유 링크를 제공합니다. 오래된 공유 링크는 현재 시세로 조용히 바꾸지 않고 재견적을 안내합니다.

| API | 동작 |
| --- | --- |
| GET /api/health | 연결 상태·데이터 모드 |
| GET /api/catalog | 실제 표준 스냅샷 |
| POST /api/requirements | 자연어 구조화 |
| POST /api/recommend | 현재 실제 카탈로그로 추천 |
| POST /api/quotes | 현재 SKU·가격·유효성·스냅샷·호환성 재검증 후 SQLite 저장 |
| GET /api/quotes | 저장 견적 |
| GET /api/pipeline/status | 수집 상태·검수 큐 |
| POST /api/pipeline/run | 로컬에서 수집 실행 |
| GET /api/prices/history?partId=c2 | 실제 가격 이력 |

서비스 인증·매장별 권한·다중 테넌트·결제는 아직 구현되지 않았습니다. 로컬 API를 그대로 인터넷에 노출하면 안 됩니다. API 키는 서버 전용이며 브라우저용 `VITE_` 변수에 넣지 않습니다. 고객 보기는 화면 모드이며 인증 경계가 아닙니다.

## 테스트

엔진/HTTP API/컴포넌트 흐름에 더해 가격 이상치 격리, 데이터 만료, 잘못된 SKU·통화 거부, RAM 키트와 GPU 커넥터 파싱, 공식 Blender 형식의 스트리밍 집계, 실데이터 화면 로드, 미확인 호환성 발행 차단을 검증합니다. 외부 네트워크 없이 반복 실행할 수 있습니다. 연결된 브라우저가 없어 실제 렌더링/인쇄 화면의 시각적 검증은 수행하지 못했습니다.
