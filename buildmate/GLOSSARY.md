# Dr.Robot 도메인 용어

## Language

**제품 유형**: 상품이 실제로 수행하는 역할에 따른 분류. 판매처의 진열 카테고리와 구별한다.

**제품 사실**: 특정 제품의 속성 값과 그 값을 뒷받침하는 출처·관측 시각의 묶음.

**조건부 호환성**: 지정된 부품·버전·장착 조건이 충족될 때 성립하는 관계. 조건을 확인할 수 없으면 미확인이다.

**검증 상태**: 관계나 사실의 확인 수준. 통과·불합격·미확인을 구분한다.

**용도 실측**: 프로그램·해상도·설정·측정 단위와 대상 구성이 명시된 실제 성능 측정.

**대체 지수**: 해당 용도를 직접 측정한 값 대신 비교에 사용하는 다른 작업의 성능 지수.

**탐색 보장 범위**: 추천이 전체 후보 또는 제한된 후보 중 어느 범위에서 선택되었는지를 나타내는 정보.

**게임 목표 조건**: 고객이 원하는 게임·해상도·화질·프레임 수준·렌더링 방식의 조합. 말하지 않은 항목의 서비스 기본값과 고객이 직접 지정한 항목은 구분한다.

**공식 요구 사양 근거**: 게임 개발사나 배급사가 게시한 하드웨어 요구와 그 적용 조건. 실측 FPS와 동일한 의미로 취급하지 않는다.

**게임 실측 기록**: 특정 게임과 테스트 구성·설정에서 관측되어 원 출처가 게시한 성능 결과. 평균 FPS와 하위 성능 지표는 서로 다른 값이다.

**근거 적용 범위**: 게임 목표 조건과 출처의 측정 조건이 일치하는 범위. 알려지지 않은 조건을 동일한 조건으로 간주하지 않는다.
