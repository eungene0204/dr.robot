# Intent: 부품별 상세 비교에서 발행할 견적 선택

## 문제와 이유

발행할 견적은 위쪽 카드를 눌러야만 바뀌어, 상세 비교표를 보면서 어떤 안을 발행할지 정하기 어렵다.

## 기대 결과

부품별 상세 비교 표의 안 이름(최적 균형안·성능 강화안·절약안) 옆 체크박스로 발행 대상을 고르고, "선택안 견적서 발행"이 그 안을 발행한다.

## 영향받는 사용자와 시스템

상담 직원·고객, src/main.jsx 비교표 머리글, 기존 `selected` 상태(카드 선택과 공유).

## 범위

- 포함: 비교표 머리글 체크박스, 카드 선택과 동기화.
- 제외: 여러 안 동시 발행, 발행 API 변경.

## 제약

견적서는 한 번에 한 안만 발행한다. 없는 안(구성 없음)은 선택할 수 없다.

## 수용 기준

- [ ] 체크박스를 누르면 해당 안만 체크되고 이전 안은 해제된다.
- [ ] 카드를 눌러 선택해도 체크박스가 같이 바뀐다.
- [ ] "선택안 견적서 발행"이 체크된 안을 발행한다.
- [ ] 구성이 없는 안의 체크박스는 비활성이다.

## 가정과 열린 질문

- 가정: "체크박스"를 단일 선택(항상 한 안이 체크됨)으로 해석했다. 체크를 직접 해제하면 발행 대상이 없어지므로 해제는 허용하지 않는다.
- 질문: 없음
