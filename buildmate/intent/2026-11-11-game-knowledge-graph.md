# Intent: 게임 지식 그래프 기반 견적

- 작성일: 2026-11-11
- 작성자: Codex

- 상태: 구현 완료
- 요청자/제품 책임자 검토: 미검토

## 문제와 기대 결과
현재 게임 공통 최소 사양과 Blender 대체 지수로만 GPU를 고른다. 인터넷의 공식 요구 사양과 원본 벤치마크를 사전에 수집한 지식 그래프에서 게임별 근거를 조회해 견적 후보를 결정하고, 적용 조건·출처·부족한 근거를 표시한다.

## 범위와 제약
- 게임·공식 요구 사양·하드웨어·실측·출처 노드와 관계를 갖는 버전 관리 그래프, 검증/조회 CLI와 읽기 API.
- 우선 8게임 공식 사양 및 확인 가능한 원본 측정부터 수집. 공식 권장과 실측 평균/하위 지표를 분리한다.
- 알려진 게임은 그래프를 로컬 조회해 요구를 해석하고 추천 엔진에 연결. 해상도·설정·목표 FPS·프레임 생성 등의 적용 조건을 확인한다.
- 미지정 목표의 기본값은 서비스 정책으로 구분. 실측의 다른 CPU·메모리·패치/드라이버 조건을 현재 견적의 보장 FPS로 바꾸지 않는다.
- 출처 없음·검토되지 않은 기록·만료 근거·다른 해상도는 확정 근거로 사용하지 않는다. 데이터가 없는 조건을 임의 생성하지 않고 명시적 목표의 근거 부족을 표시한다.
- 기존 예산·호환·고객 직접 지정·과잉 사양 방지 및 모호한 요청의 안전 경로 유지. 견적 때 인터넷/모델로 새 사실을 생성하지 않는다.

- [x] 게임별 그래프 조회가 실제 GPU 후보·RAM/저장장치 기준 및 설명에 반영된다.
- [x] 미지원 FPS·해상도·모드 및 복수 게임에서 잘못된 FPS 보장을 하지 않는다.
- [x] 사용자 명시 조건과 예산·호환성·고사양 요구 및 기존 추천 회귀를 보존한다.
- [x] UI/API에 게임 근거와 출처·적용 한계를 표시한다.

- 최초 배포는 로컬 버전 관리 그래프이며 외부 그래프 DB 설치 없이 빠르게 조회한다.
- 질문: 없음.

## 구현 및 검증 결과
- 공식 8게임/17프로필, 원본 실측 4개. 107노드·121관계, 하드웨어 VRAM 변형과 대안 OR 관계 보존. 검증/조회 CLI와 두 읽기 API 제공.
- `min_specs/base_pools`가 그래프에서 GPU 후보·공식 용량 하한을 조회. 예산 상한과 호환성 유지, 미측정 상위 GPU로 자동 대체 금지.
- 해상도·목표·설정 미지원, 만료/미검토 출처, 복수 게임, 사용자 GPU/최고 성능 요청 회귀 검증. 원본 평균과 실제 견적 FPS 보장을 구분.
- UI는 health의 게임 별칭으로 모델을 생략하고 응답의 정규화 해상도 및 근거/출처를 표시한다. UI 회귀 테스트로 확인.
- Python333개, JS/UI100개, Vite build 통과. 실제 카탈로그14시나리오 통과. [상세 기록](../../pcquote/docs/evaluations/2026-11-11-game-knowledge.md).
- 자동 검증과 로컬 서버 API 반영을 기준으로 구현 완료. 요청자/제품 책임자 검토는 미검토 상태를 유지한다.
- 최초 구현 시 원본 실측은 2게임 FHD에 한정되었다. 6게임과 QHD/4K 등은 coverage_gap이며 일반 규칙을 사용한다. 자동 수집/갱신은 구현하지 않았고 재검토 기한 초과 근거는 조회에서 제외한다.
