# Intent: 근거 기반 LLM 상담 하네스

## 문제와 이유

LLM은 상담 문장을 견적 조건으로 해석하는 데만 쓰이고, "5060ti로 4k 게임 되나?" 같은 질문에는 카탈로그 수치만 나열한다. 요청자는 견적은 물론 이런 질문에도 대답하기를 원한다("이제 llm을 위한 하네스 엔지니어링을 시작해").

## 기대 결과

상담 중 질문에 LLM이 한국어로 직접 답한다. 답변은 서버가 모은 근거(언급된 제품의 카탈로그 정보, 현재 견적 구성, 데이터 한계)를 바탕으로 하며, 근거에 없는 가격이나 FPS 수치를 지어내지 않는다. 일반적인 업계 평가는 그것이 일반 지식임을 밝히고 쓴다. LLM을 쓸 수 없거나 검사를 통과하지 못하면 기존 카탈로그 답변으로 대체한다.

## 영향받는 사용자와 시스템

상담 화면의 질문 답변, 신규 POST /api/answer, backend의 LLM 호출 공통부, 기존 POST /api/requirements.

## 범위

- 포함: LLM 호출 공통 모듈(모델 대체, reasoning 비활성, 재시도, 사용량 기록), 근거 수집, 답변 프롬프트·구조화 출력, 출력 검사(근거 밖 가격·FPS 수치·길이)와 위반 시 1회 교정 재요청, 실패 시 규칙 답변 대체, 최근 대화와 현재 견적을 맥락으로 전달, 실제 모델 대상 평가 스크립트.
- 제외: 답변에 견적·버튼 첨부, 웹 검색, 게임 FPS 데이터 수집, 질문/견적 판별의 LLM 전환.

## 제약

키는 서버에만 둔다. 사용자 문장과 대화는 데이터로 다루고 지시문으로 실행하지 않는다. 가격은 근거에 있는 값만 쓴다. 게임 FPS 실측 자료가 없으므로 구체적 프레임 수치를 단정하지 않는다.

## 수용 기준

- [x] LLM 설정 시 "5060ti로 4k 게임을 플레이 할 수 있나?"에 카탈로그 근거(VRAM 등)와 4K에 대한 판단을 담은 한국어 답변이 나온다.
- [x] 근거에 없는 원화 금액이나 FPS 수치가 담긴 답변은 교정 재요청 후에도 위반이면 규칙 답변으로 대체된다.
- [x] 현재 견적에 대한 질문("이 견적으로 배그 되나?")에 견적 부품을 근거로 답한다.
- [x] LLM 미설정·오류 시 기존 카탈로그 답변이 나온다.
- [x] 평가 스크립트가 실제 모델로 대표 질문을 실행하고 검사 결과를 보고한다.

## 가정과 열린 질문

- 가정: 질문/견적 판별은 기존 규칙(isQuestion)을 유지한다. 무료 모델의 응답 품질·속도 제한은 평가로 확인한다.
- 질문: 없음

## 구현 및 검증 결과

- 관련 코드·문서: backend/llm.mjs(호출 공통부), backend/answer-harness.mjs(근거 수집·프롬프트·검사·교정·대체), backend/server.mjs(POST /api/answer, 요구 해석의 공통부 사용), src/main.jsx(질문 → /api/answer, 근거 종류 표시), src/question-answer.mjs(견적 요청 판별 보정), scripts/llm-eval.mjs(npm run eval:llm), tests/answer-harness.test.mjs, tests/ui.test.mjs, tests/engine.test.mjs
- 수용 기준별 검증: 실제 API에서 '5060ti로 4k 게임을 플레이 할 수 있나?' → VRAM 8·16GB, 최저가(718,900원/860,000원), 옵션·업스케일링 조건, FPS 수치 없음, 약 1~2초. 단위 테스트로 FPS·근거 밖 금액 위반 → 교정 1회 → 재위반 시 카탈로그 답변, LLM 오류·미설정 시 카탈로그 답변 확인. 평가 스크립트 7개 질문(5060 Ti 4K, CPU 비교, 최저가, 견적 기반 배그, 안 비교, 지시 무시 유도, 파워 용량) 7/7 통과. UI 테스트로 견적 부품 id·최근 대화 전송과 근거 표시 확인. '이 견적으로 배그 되나?'가 견적 요청으로 분류되던 문제를 함께 수정. 전체 테스트 93개·빌드 통과.
- 남은 항목: 검사는 금액·FPS 수치·형식만 기계적으로 확인하며 부품 비교 서술의 사실 오류는 잡지 못한다(평가 중 균형안·절약안의 CPU가 '비슷하다'고 쓴 사례 1건). 무료 모델은 묻지 않은 한계 문구(배송비 등)를 덧붙이는 경향이 남아 있고 응답이 때때로 6~12초 걸린다. 브라우저 화면 직접 확인은 미확인.
