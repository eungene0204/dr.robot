# Intent: 게임 견적 라우팅과 온라인 요구 사양 조회

- 작성일: 2026-11-12
- 작성자: Codex
- 요청자: 사용자
- 상태: 완료
- 요청자/제품 책임자 검토: 미검토

## 문제와 기대 결과
‘사이버 펑크 견적은?’이 부품 질문으로 처리되어 카탈로그 오류가 나온다. 게임 견적 요청은 추천으로 보내고, 게임 질문은 로컬 지식을 먼저 확인한다. 로컬에 없는 게임은 Steam 공식 스토어에서 검색하고 Windows 요구 사양과 출처를 안내한다.

## 범위와 제약
- 알려진 게임은 네트워크 없이 조회. 사이버펑크 짧은 한글 별칭과 견적 요청의 의문형 지원.
- 미등록 게임은 Steam 검색/상세를 조회. 정확한 제목을 확인한 결과만 사용하고 모호하면 후보와 재질문, 미검색·시간초과·Windows 사양 미공개는 명시한다.
- 온라인 요구 사양은 검수된 그래프와 분리하여 짧게 캐시하고 출처·조회일을 표시한다. 공식 RAM/설치 용량을 추천 하한에 반영하며 CPU/GPU의 성능 동등성·게임 FPS를 생성하지 않는다.
- 기본 온라인 범위는 Steam Windows 게임. 다른 스토어·공식 사이트의 범용 크롤링은 포함하지 않는다. 검색에 고객 전체 대화·예산을 보내지 않고 추출한 게임명만 보낸다.
- 기존 예산 상한·사용자 직접 지정·호환 검사·일반 제품 질문 보존. 클라이언트의 사양/출처 주장은 신뢰하지 않는다.

## 수용 기준
- [x] 원문 ‘사이버 펑크 견적은?’이 질문 답변 대신 실제 추천 경로로 간다.
- [x] 알려진 게임 질문은 모델 설정과 무관하게 게임 근거로 답하고 출처를 표시한다.
- [x] 없는 게임은 온라인 검색·공식 Windows 사양 조회 후 출처와 조회일을 표시하며 RAM/저장 용량 하한을 추천에 사용한다.
- [x] 모호한 제목·검색 실패·시간초과·사양 미공개에 잘못된 게임이나 사양을 확정하지 않는다.
- [x] 자동 회귀·빌드와 실제 온라인 조회를 검증하고 관련 문서를 갱신한다.

## 가정과 열린 질문
- 가정: 추가 검색 API 키 없이 접근 가능한 Steam 공개 스토어를 첫 온라인 검색 소스로 삼는다.
- 질문: 없음.

## 구현 및 검증 결과
- 원문을 `isQuestion`에 입력한 실패 재현 후 분류를 수정했다. UI 검사에서 ‘사이버 펑크 견적은?’이 답변 API를 호출하지 않고 실제 추천 경로로 가는 것을 확인했다.
- `pcquote.game_search`와 `/api/requirements`, `/api/answer`, `screen.to_request`를 연결했다. LLM 없이 로컬/온라인 게임 조회, 출처·확인일 표시, 제목 미확정 시 정지, 사무→게임 주제 전환을 검사했다.
- 검색/요구 사양 응답은 고정 Steam 호스트에 한정. 중복 제목·실패·timeout·JSON 오류·DLC·사양 미공개, 캐시 만료/복사 격리 및 제목만 전송하는 검사를 통과했다. 공식 용량 하한이 고객 선호 포기와 예산 완화 후에도 유지됨을 검사했다.
- 실제 Steam 조회: `Hades II` 공식 Windows 최소/권장 프로필2개 및 출처 확인. ‘하데스 2’는 검색 결과가 없음을 확인해 영문 정식 제목 재입력 안내가 작동했다. 모든 한국어 약칭을 자동 번역하는 기능은 없다.
- 운영 카탈로그로 `사이버 펑크 견적은?`, `Hades II 견적은?` 각각3안 생성, 호환 실패0 및 FPS 보장 false 확인. 가격을 새로 수집한 검증은 아니다.
- 서버 재시작 후 실제 8001 `/api/health`, `/api/requirements`, `/api/answer`와 최신 UI 번들 제공을 확인했다. 실제 사용자 브라우저 클릭은 미실행이며 UI 경로는 JSDOM으로 검증했다.
- 검증 집계: backend395개, JS/UI106개, Vite build 및 diff 검사 통과. [문제 해결 기록](../troubleshooting.md#2026-11-12-의문형-게임-견적이-부품-조회로-처리됨).
- 남은 지원 범위: Steam 외 게임은 공식 사양 자동 검색 대상이 아니며, 공식 CPU/GPU와 현재 제품의 동등 성능이나 FPS를 확정하지 않는다. 요청자/제품 책임자 검토는 미검토다.
