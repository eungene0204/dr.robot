# 견적 에이전트 전환
상태: 진행 중. 사용자 검토: 미검토.
요청: 기존 모델을 유지하면서 Agents SDK의 판단·도구·상태·실행 제어·가드레일로 견적을 생성한다.
범위: live 견적 경로, PostgreSQL 실행 상태, 기존 가격·호환성 검증 재사용. 데모와 일반 제품 질문은 유지한다.
수용 기준: 화면에서 에이전트 호출, 기존 모델 도구 호출 확인, 실패 시 가짜 견적 없음, 실행 상태 저장, 회귀 검사·빌드 통과.

검증 결과: 완료. 사용자 검토: 미검토.
- 화면 경로 전환: UI 21개 포함 전체 프런트 107개 통과.
- 기존 모델: k-exaone_v2.5 실도구 호출 성공.
- 가격·출력 차단·실행 저장: 새 통합 테스트 포함 백엔드 408개 통과.
- 실제 견적: 100만원 사무용, 36.84초, 원문 가격 15건 오류 없이 갱신, 3안 모두 예산 이내.
- 빌드 통과. 실제 브라우저 수동 조작은 미실행이며 jsdom UI 검사로 확인했다.

## 15초 목표 후속 개선
상태: 진행 중. 기존 모델 유지와 원문 가격 재확인을 보존한다. 명확한 용도는 서버 규칙으로 판단하고, 모호한 요청만 LLM 계획을 실행한다. 대화형 수집 간격은 robots Crawl-delay를 우선하며 야간 수집과 분리한다. 실제 100만원 사무용 재측정에서 15초 이하 여부를 기록한다. 외부 429·지연 상황의 절대 상한으로 주장하지 않는다.

15초 목표 후속 결과: 측정 사례에서 완료. 최종 설정으로 사무용 8.45초·게임용 9.46초/12.39초, 모두 3안과 15건 원문 확인·오류 0. 백엔드 410개 통과. 재실행 가능한 benchmark_quote_agent.py는 15초 초과 시 실패한다. 외부 지연·모델 추론이 필요한 요청의 절대 상한은 보장하지 않는다.

실행 반영 보완: 구버전 서버의 405를 재현하고 최신 코드로 재시작했다. 사용자 실제 문장을 5588 프록시에 보내 HTTP 200·3안·8.98초로 확인했다. 405의 사용자 안내를 구체화했다.
