## 문제와 기대 결과
동일한 MSI RTX 5060 상품(122676813)이 다나와698,850원, 우리 화면689,000원으로 다르다. 기존24시간 유효 가격도 견적 생성 시 원문을 다시 확인하고 현재 일반 최저가를 사용한다. 갱신된 카탈로그의 가격은 열려 있는 미발행 견적의 부품 금액과 합계에도 반영한다.

## 범위와 제약
- 모든 선택된 실제 부품을 생성/재생성 때 조회하고 수동 교체 부품도 반영 전에 재조회하며, 실패 부품 또는 확인 한도 안에 검증되지 않은 구성은 반환하지 않는다. 가격 변동 후 재계획된 부품도 확인한다.
- 일반 최저가 기준. 배송비·회원/카드 혜택가는 제외한다. 외부 사이트에서 조회 이후 가격이 바뀔 수 있으므로 확인 시각을 표시한다.
- 기존 검수 큐·예산·호환 검사 유지. 현재 GPU 가격을 원문 관측에 근거해 DB에 반영한다. 과거 발행 문서는 보존한다.
- 미발행 화면은 같은 부품의 새 가격과 합계를 반영하되 기존 카탈로그 변경/발행 전 재생성 검증을 우회하지 않는다.

## 수용 기준
- [x] 최근 가격도 견적 생성 시 재조회하며 최종 반환된 실제 부품은 모두 확인된 가격이다. 수동 교체의 새 부품도 재조회한 가격과 서버 합계로 반영한다.
- [x] 조회 실패·변동 검수·재계획 한도 도달 시 미확인 가격 구성을 노출하지 않는다.
- [x] 미발행 화면의 같은 상품 가격·합계가 최신 카탈로그로 갱신되고 발행 문서는 유지된다.
- [x] 상품122676813의 DB/API 가격이 실제 관측한 다나와 일반 최저가와 일치한다.
- [x] 회귀 검사·빌드와 문서 갱신을 마친다.

## 구현 및 검증 결과
- 동일 상품 코드122676813의 DB689,000원과 실제 다나와/파서698,850원을 대조했다. 최근24시간 관측을 재조회하지 않는 API 실패와 갱신 카탈로그가 화면 금액·합계에 반영되지 않는 UI 실패를 재현한 뒤 수정했다.
- 요청 내 attempted/verified 집합으로 공유 부품을 한 번만 수집하고, 가격 변경 후 재계획을 확인한다. 확인 한도에서 미확인 부품이 남는 구성은 제거한다. 최근 가격의 재조회 실패와30% 변동 검수는 기존 가격 재사용 대신 제외/검수로 처리한다.
- 수동 교체는 refreshPartId를 검증하고 현재 가격을 확인한 뒤 서버의 canonical parts/total/catalogVersion으로 반영한다. 실패 시 교체를 반영하지 않는다. 선택하지 않은 ID 요청도 거부한다.
- 화면의 더 새로운 카탈로그 관측은 동일 부품 금액·합계와 최초 추천 복원 기준에 반영한다. 기존 카탈로그 버전/발행 전 재검증을 유지하고 발행 문서 모달의 스냅샷은 보존한다. 가격 툴팁에 확인 시각을 제공한다.
- 실제 GPU 재수집으로 DB/API698,850원 확인. 서버 재시작 후 실제 추천 요청에서21개 가격 갱신·확인 실패 후보1개 제외·견적3안 생성. 세 안의 MSI GPU698,850원, 모든 반환 실제 부품의 관측 시각이 해당 요청 이후임을 검사했다. 세 안 합계1,643,570/1,841,290/1,283,530원은 해당 관측 시점 기준이다.
- 실제 수동 교체에서도 g1의 원문 가격698,850원·새 관측 시각·합계1,662,430원 및 호환 실패0 확인. JSON-LD가 없는 별도 ZOTAC 후보는 교체 실패로 차단되는 것도 확인했다.
- backend399개·JS/UI107개·Vite build·diff 검사 통과. 원문 가격·일반 제품 질문·게임 조회·발행/교체 회귀 포함. 실제 서버의 최신 번들 제공 확인. 사용자 브라우저 직접 조작은 미실행이며 UI 동작은 JSDOM으로 확인했다.
- 관련 코드: screen.py, main.py, main.jsx. [원인/재발 방지](../troubleshooting.md#2026-11-12-다나와-원문-가격과-화면-가격-불일치).
- 한계: 외부 사이트 조회 이후의 가격 변동·배송비·조건부 혜택가는 별도이며 수집 실패 자료로 금액을 생성하지 않는다. 요청자 검토는 미검토.
