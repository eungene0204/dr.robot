# Intent: 예산 미지정 요청의 과잉 사양 추천 방지

- 작성일: 2026-11-11
- 작성자: Codex
- 요청자: 사용자
- 상태: 완료
- 요청자/제품 책임자 검토: 미검토

## 문제와 기대 결과
“오버워치용 견적”에 GPU만 1,060만원인 RTX 5090이 나왔다. budget=None 분기가 최고 성능을 강제해 게임 필요 수준이나 비용 절충 없이 최상급을 고른다. 예산 미지정은 용도 충족과 가격 균형을 기본으로 하고, 최고 성능은 명시 요청일 때만 제공한다.

## 범위와 제약
Python 실서비스와 JS 데모의 무예산 추천에 같은 목적 적합 정책을 적용한다. GPU는 최소 사양을 충족하는 유효 후보의 성능 범위와 비용 여유 안에서 고른다. 고객 예산을 임의 금액으로 만들지 않으며 budget/budgetCap=None을 유지한다. 최고 성능 명시·GPU 모델 지정·AI VRAM 등 실제 요청은 존중한다. 유한 예산과 호환·최소 사양 검사는 유지한다. 게임 FPS 실측 자료가 없는 상태에서 특정 FPS나 성능 보장을 만들지 않는다.

## 수용 기준
- [x] 기본 오버워치 및 일반 게임의 무예산 요청이 중급 대안이 있는데 5090을 자동 추천하지 않는다.
- [x] 인기 순위가 높은 최상급 GPU도 기본 적합 범위를 넘어 추천되지 않는다.
- [x] 명시 최고 성능/5090 지정/32GB VRAM 등 실제 고사양 요청은 차단하지 않는다.
- [x] 세 안의 비용/성능 순서, 예산·최소 사양·호환성 및 예산 미지정 발행이 유지된다.
- [x] 실제 저장 카탈로그의 원문 재현과 목적별 회귀 평가를 수행한다.

## 가정과 열린 질문
- 게임별 FPS 목표가 없는 기본 추천은 기존 해상도별 최소 기준을 출발점으로 삼는다. 목적 적합 범위는 서비스의 비용 절충 정책이며 게임별 실측 보장은 아니다.
- 질문: 없음.

## 구현 및 검증 결과
- 원래 실패를 fixture 실제 엔진에서 재현: 균형/성능5090·절약5060Ti. 유한 예산/게임명 대조로 budget=None 최고 성능 강제 분기가 원인임을 확인.
- 목적 적합 범위를 최고점 선택 전에 적용. GPU 참조 지수와 비용 여유 각각1.5배(서비스 휴리스틱), 고객 예산·FPS 목표를 만들어내지 않음. 명시 최대 성능/GPU/VRAM 예외 보존. 인기 순위는 적정 범위를 넓히지 않음. 중급 가격 실패 때 최상급으로 자동 승급하는 추가 실패도 재현 후 차단.
- Python과 JS 데모·UI 안내, 오버워치 이름 판별, SRS/구조 문서 갱신.
- 최종 백엔드296개·JS/화면98개·빌드·공백 검사 통과. 실제 카탈로그16개/48안 감사 모두PASS. 원문 실제 API 해석 gaming/QHD/None/EXAONE9.4초 후 세 안 모두5060Ti, budgetCap=None·호환 검사 통과.
- 서버 반영 완료. 원본 및 범위는 [보고서](../../pcquote/docs/evaluations/2026-11-11-purpose-fit-quotes.md) 참조.
- 남은 검증: 실시간 시세·모든 게임 FPS·브라우저 직접 조작은 미검증. 유한 예산 배분 정책은 이번 변경 범위에서 유지. 기존 저장 견적은 자동으로 수정하지 않으며 재생성 시 새 정책 적용. 요청자 검토 미검토 유지.
