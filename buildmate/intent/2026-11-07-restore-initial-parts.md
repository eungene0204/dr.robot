# Intent: 부품 목록을 최초 추천 부품으로 되돌리기

- 작성일: 2026-11-07
- 요청자: 사용자 ("부품 리스트에 최초 추천 부품으로 돌릴수 있는 버튼을 만들어줘")
- 작성자: Claude
- 상태: 완료
- 요청자/제품 책임자 검토: 미검토

## 문제와 이유

상담 중 부품을 여러 개 교체하면 처음 추천받은 구성으로 돌아갈 방법이 없다. 부품마다 다시 찾아 바꾸거나 견적을 새로 만들어야 한다.

## 기대 결과

"부품별 상세 비교" 표 머리글(안 이름 옆)의 "최초 추천" 버튼으로 그 안의 부품·합계·호환성 결과를 견적 생성 직후 상태로 한 번에 되돌린다.

## 영향받는 사용자와 시스템

상담 직원. buildmate `src/main.jsx`(부품별 상세 비교 표), `src/style.css`.

## 범위

- 포함: 견적 생성·재생성 때 안마다 최초 추천 스냅샷 보관(상담 세션 저장에도 유지), 교체한 부품이 있을 때만 버튼 활성, 되돌린 뒤 안내 토스트.
- 제외: 부품 하나씩 되돌리기, 불러온 발행 견적·공유 링크 견적(스냅샷 없음, 버튼 숨김). 발행 저장에는 스냅샷을 넣지 않는다.

## 제약

되돌린 구성은 생성 당시 가격·검증 결과 그대로다. 그사이 카탈로그가 바뀌었으면 기존 발행 전 확인(카탈로그 버전·가격 재검증)이 그대로 막는다.

## 수용 기준

- [x] 교체 전 버튼 비활성, 교체 후 활성
- [x] 누르면 최초 추천 CPU와 합계로 복원되고 버튼이 다시 비활성
- [x] 실제 브라우저(Chrome 헤드리스, 개발 서버 5588)에서 머리글 배치와 교체 후 활성 확인
