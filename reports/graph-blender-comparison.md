# 제품 관계 검증과 Blender 지수 비교

실행: 2026-11-06 KST. 원시 결과·시각·카탈로그 버전은 graph-blender-comparison.json 참조.
재실행: `node scripts/compare-recommendation-basis.mjs`

## 비교 범위

그래프와 Blender는 서로 대체되는 추천 엔진이 아니다. 현재 추천은 제품 속성과 공통 검증 함수로 후보를 제한하고 Blender 대체 지수로 순위를 매긴다. SQLite 관계 테이블을 순회해 별도 점수를 산출하는 그래프 추천 알고리즘은 없다.

아래 후보 수 비교의 기준선은 가격 신선도·판매 상태·CPU/GPU Blender 자료 유효성이다. 이전 버전의 추천 엔진 전체를 재현한 기준선이 아니며, 추천 정확도 A/B 시험도 아니다. 후보 수 감소를 정확도 향상률로 해석할 수 없다.

## 실제 데이터 결과

- 실물 제품: 6,827개. 가상 선택지 2개는 통계에서 제외.
- 가격·Blender 자료 조건을 통과한 제품: 5,590개.
- 제품 유형·필수 속성 검증까지 통과한 제품: 4,035개.
- 추가로 제외된 제품: 1,555개. 잘못된 유형과 필수 정보 누락 등이 포함되며 모두 물리적으로 불가능한 제품이라는 뜻은 아니다.
- StorageAccessory 239개 중 기준선 통과는 229개, 유형 검증 통과는 0개.
- KS507 컨버터: 기준선 통과, 유형·저장 용량 검증에서 차단.

## 두 기능의 차이

| 항목 | 제품 관계·유형 검증 | Blender 대체 지수 |
| --- | --- | --- |
| 질문 | 이 제품이 해당 역할을 할 수 있고 조건에 맞는가? | 이 CPU/GPU의 렌더 성능 지수는 어느 정도인가? |
| 결과 | 통과·불합격·미확인, 조건과 근거 | 수치와 벤치마크 근거 |
| 컨버터 문제 | 액세서리 분류·용량 누락으로 차단 | SSD에는 CPU/GPU 성능 점수를 적용하지 않아 문제를 직접 검출하지 못함 |
| BIOS 문제 | 지원 목록·리비전·설치 버전 조건 평가 | 판단하지 않음 |
| 게임 FPS·AI 처리량 | 관계만으로 수치를 생성하지 못함 | 해당 용도의 직접 실측이 아님 |

조립비 30,000원 포함. 아래 지수는 용도별 가중치가 달라 서로 다른 용도 사이에서 단순 비교하지 않는다.

모두 현재 구현된 검사 21개를 통과했다. 전역 최적성이나 모든 실제 장착 조건을 보증하는 결과는 아니다. 속도는 한 번의 로컬 실행 관측값이다. 가격 자료의 만료에 따라 재실행 결과가 달라질 수 있다.

## 드러난 한계

1. 게임과 AI가 동일한 CPU/GPU 가중치를 사용해 균형안이 같았다. AI 모델·양자화·메모리 요구·프레임워크 호환성 실측을 반영하지 않는다.
2. 편집 이외의 최소 저장 공간 정책이 없어 128GB SSD가 선택됐다. 실제 드라이브라는 검증과 사용 목적에 충분하다는 검증은 별개다.
3. M.2 슬롯 수 검사가 모든 SATA/NVMe 프로토콜·슬롯 공유·장착 조건을 다루지는 않는다. 해당 관계와 제조사 근거를 확충해야 한다.
4. 검수된 용도별 직접 실측은 운영 DB에 아직 0건이다. 따라서 FPS나 AI 속도의 정확도를 비교하는 실험은 수행할 수 없다.

## 후속 작업

용도별 최소·권장 저장 공간과 확장 조건을 정의하고, 저장 인터페이스의 제조사 근거를 추가한다. 용도 실측을 확보한 뒤 같은 예산·작업·설정에서 실제 성능과 예측·선택 결과를 비교해야 한다.
