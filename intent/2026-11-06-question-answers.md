# Intent: 상담 중 질문에 근거 답변

- 작성일: 2026-11-06
- 요청자: 사용자
- 작성자: Claude Code
- 상태: 완료
- 요청자/제품 책임자 검토: 미검토

## 문제와 이유

'5060ti로 4k 게임을 돌릴수 있나?'처럼 질문을 보내도 모든 입력을 견적 생성으로 처리해, 질문에 답하지 않고 이전 상담의 200만원 예산으로 게임 견적을 만들었다. 언급한 GPU도 견적에 반영되지 않았다.

## 기대 결과

질문은 견적을 만들지 않고 카탈로그 근거(제품 수, VRAM, 최저가, Blender 지수)로 답하며, 게임 FPS 실측 자료가 없음을 밝힌다. 답변에는 견적 버튼을 붙이지 않는다(같은 날 변경). 견적은 그 견적을 만든 답변 바로 아래에 고정되고, 이후 대화는 그 아래에 차례대로 이어 붙는다. 용도가 바뀐 새 요청은 이전 문장과 예산을 이어받지 않는다.

## 영향받는 사용자와 시스템

상담 화면(src/main.jsx), src/question-answer.mjs, src/engine.mjs(parseRequirement.models, recommend의 모델 고정).

## 범위

- 포함: 질문 판별, 카탈로그 근거 답변, 견적 아래로 이어지는 대화 배치, CPU·GPU 모델명 고정, 용도 변경 시 예산·이전 문장 초기화.
- 제외: LLM 자연어 답변, 게임 FPS 추정, 메모리·SSD 등 다른 부품의 모델 고정.

## 제약

FPS·실행 가능 여부를 단정하지 않는다. Blender 지수가 게임 FPS가 아님을 표시한다. 같은 용도의 추가 요청(예: 화이트로)은 기존 예산을 유지한다.

## 수용 기준

- [x] 편집 견적 후 '5060ti로 4k 게임을 돌릴수 있나?'를 보내면 기존 견적은 그대로이고 RTX 5060 Ti 근거와 FPS 실측 부재를 답한다.
- [x] 질문 답변은 기존 견적 아래에 붙고, 견적 영역을 다시 그리지 않으며, 버튼이 없다.
- [x] 용도가 바뀐 '5060ti 게임 4K 견적'은 '게임 · 4K', 예산 제한 없음으로 모든 안에 RTX 5060 Ti가 포함된다.
- [x] 견적 요청 문장('200만원 이하 adobe용 견적', '…견적 짜줘?')은 질문으로 처리하지 않는다.

## 가정과 열린 질문

- 가정: 질문 판별은 물음표·의문 어미 기반이며 '견적·추천해·짜줘' 등이 있으면 견적 요청으로 본다. 용도 변경은 새 문장의 용도 키워드가 기존 견적 용도와 다를 때로 판단한다.
- 질문: 없음

## 구현 및 검증 결과

- 관련 코드·문서: src/question-answer.mjs, src/engine.mjs, src/main.jsx, src/style.css, tests/ui.test.mjs, tests/engine.test.mjs
- 수용 기준별 검증: UI 테스트(편집 견적 → 질문 → 근거 답변이 같은 견적 요소 아래 표시·버튼 없음 → 견적 요청 → 게임·4K·예산 제한 없음·전 안 5060 Ti)와 질문/모델 추출 단위 테스트 통과. 전체 테스트 87개 통과. 실제 API에서 '5060ti 게임 4K 견적' 세 안 모두 5060 Ti 포함 확인.
- 남은 항목: 브라우저 화면 직접 확인은 미실행(개발 서버 HMR 반영 전제). 특정 게임 FPS 질문에는 근거가 없어 답하지 못한다.
- 변경(같은 날, 요청자 피드백): 질문 답변의 견적 버튼을 없앴다. 견적 결과는 그것을 만든 답변 바로 아래에 렌더링하고 이후 대화를 그 아래에 이어 붙인다(메시지의 quote 표시 기준). 불러온 견적은 대화 끝에 표시한다.
