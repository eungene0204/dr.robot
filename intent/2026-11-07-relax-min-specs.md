# Intent: 예산이 최소 사양보다 낮을 때 사양을 낮춰 견적 제시

- 작성일: 2026-11-07
- 요청자: 사용자
- 작성자: Claude
- 상태: 진행 중
- 요청자/제품 책임자 검토: 미검토

## 문제와 이유

예산을 상한으로 바꾼 뒤([기록](../troubleshooting.md#2026-11-07-budget-over-and-flat-prices)) 게임 QHD 150만 원처럼 예산이 최소 사양 견적(조립비 50,000원 기준 1,535,320원)보다 낮으면 견적이 한 건도 나오지 않는다. 요청자 결정: "2번으로 하고 안내를 하자"(2번 = 최소 사양을 낮춰 예산 안에서 맞춤).

## 기대 결과

기본 최소 사양으로 예산 안 조합이 없으면 최소 사양을 단계적으로 낮춰 예산 안 견적을 제시하고, 무엇을 낮췄는지 상담 화면에 안내한다.

## 영향받는 사용자와 시스템

상담 직원·고객, pcquote 엔진 `recommend`·`requirements`, 화면 API 응답(`notice`), buildmate 견적 메시지.

## 범위

- 포함: 낮추는 순서 ① 메모리 32GB → 16GB ② SSD 1TB → 500GB ③ 게임 그래픽카드 기준 한 단계 아래(4K → QHD 기준, QHD → FHD 기준). 앞 단계로 맞으면 거기서 멈춘다(누적 적용). 낮춘 내용을 견적 메시지에 표시.
- 제외: AI 용도 VRAM 12GB 기준, FHD 게임 그래픽카드 기준(더 낮은 기준 없음), 예산 상한 완화.

## 제약

예산 상한·호환성은 그대로 지킨다. 낮춘 사양으로도 안 되면 기존처럼 최저 가능 금액을 안내한다.

## 수용 기준

- [x] 게임 QHD 150만 원(조립비 50,000원)에서 견적이 나오고 모든 안이 예산 이하다.
- [ ] 견적 메시지에 낮춘 사양(예: 메모리 32GB → 16GB)이 표시된다. (서버 `notice`는 확인, 화면 표시는 브라우저 미확인)
- [x] 기본 사양으로 예산 안 조합이 있으면 사양을 낮추지 않고 안내도 없다.
- [x] 모든 단계를 낮춰도 안 되면 최저 가능 금액 안내가 유지된다(낮춘 사양 기준 금액으로 안내).

## 가정과 열린 질문

- 가정: 낮추는 순서(메모리 → SSD → 그래픽카드)는 게임 성능 영향이 작은 것부터로 정했다. 그래픽카드는 한 단계만 낮춘다.
- 질문: 없음

## 구현 및 검증 결과

- 관련 코드·문서: pcquote `engine/requirements.py`(`relaxed_specs`), `engine/recommend.py`(`_collect`, `recommend`, `Result.relaxed`), `screen.py`(`notice`), buildmate `src/main.jsx`(견적 메시지·재생성 토스트에 `notice` 추가), 테스트 `tests/test_recommend.py` 4건·`tests/test_api.py` 1건.
- 수용 기준별 검증: pcquote pytest 130개·buildmate npm test 79개·빌드 통과. 실제 카탈로그 화면 경로(가격 갱신 끔, 조립비 50,000원): 게임 QHD 150만 원 → 1,469,588 / 1,497,098 / 1,450,688원, 안내 "메모리 32GB → 16GB". QHD 120만 원 → 세 단계 모두 낮춤, 1,170,780~1,195,368원. 4K 150만 원 → 세 단계, 예산 이하. QHD 250만 원 → 낮추지 않음, 안내 없음. QHD 80만 원 → 견적 없음, "최소 사양을 낮춰도(…) 가능한 최저 견적은 1,126,844원".
