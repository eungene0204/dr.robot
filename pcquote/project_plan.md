### 2026-11-11 EXAONE 직접 연결

- 사용자 제공 키를 git 제외 서버 `.env`(권한 600)에 저장하고 `LLM_PROVIDER=exaone`, `EXAONE_MODEL=k-exaone_v2.5`로 전환. 서버·두 평가 도구의 제공자 설정을 통합하고 화면의 EXAONE 요구 해석도 LLM 기반으로 표시한다.
- 공식 API의 low 추론, 충분한 토큰 한도, JSON 스키마 출력 지시와 기존 결과 검증을 사용한다. 오류 시 규칙으로 대체하고 다른 제공자로 자동 전송하지 않는다.
