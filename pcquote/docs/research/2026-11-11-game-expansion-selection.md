# 추가 게임 선정 범위

확인일: 2026-11-11. 기존8게임에 **서로 다른20게임을 추가**하여28게임으로 확장한다. [Steam 공식 Most Played](https://store.steampowered.com/charts/mostplayed)의 현재 이용 게임을 참고하고, 국내 온라인 게임·대표 AAA도 포함했다. 정확한 인기 순위 상위20개라는 뜻은 아니다. 실시간 순위·동접 수는 사양 판단에 사용하지 않는다.

| 구분 | 추가 게임 |
|---|---|
| 멀티플레이·라이브 서비스 | Dota2, Rust, HELLDIVERS2, Palworld, Destiny2, Warframe, Rainbow Six Siege X, Dead by Daylight, Path of Exile2 |
| AAA·오픈월드·RPG | GTA V Enhanced, Red Dead Redemption2, Elden Ring, Baldur's Gate3, Black Myth Wukong, Monster Hunter Wilds, Diablo IV |
| 국내 수요·샌드박스 | Genshin Impact, Minecraft Java Edition, Lost Ark, MapleStory |

각 게임의 사양은 인기 차트에서 가져오지 않고 [공식 사양 A군](2026-11-11-game-expansion-a.md)과 [공식 사양 B군](2026-11-11-game-expansion-b.md)의 퍼블리셔 원문에서 수집한다. 원본 실측은 [추가 벤치마크 조사](2026-11-11-game-expansion-benchmarks.md)에서 별도로 보존한다.

에디션/지역: GTA V는 Enhanced를 대상으로 하고 Legacy를 같은 사양으로 취급하지 않는다. Minecraft는 Java Windows를 대상으로 하며 Bedrock으로 표시된 요청을 Java로 매칭하지 않는다. 로스트아크·메이플은 한국 공식 문서를 우선한다. 게임별 정확한 범위와 원문 한계는 각 조사 문서에 기록한다.
