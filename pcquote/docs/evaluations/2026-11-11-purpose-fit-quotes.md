# 오버워치 5090 과잉 추천 점검 및 수정 — 2026-11-11

## 재현과 원인
“오버워치용 견적”을 budget=None/QHD로 추천하면 균형안과 성능안에 5090, 절약안에 5060 Ti가 나오는 것을 0.3초 회귀 검사로 재현했다. 고정 테스트 카탈로그의 균형/성능 총액은 5,020,000/5,455,000원이었다. 원인은 모델이 아니라 engine/recommend.py의 무예산 분기가 best=max(performance)를 강제로 선택하는 정책이었다. 같은 요청에 유한 예산만 주면 5090이 사라지고, 게임 이름만 일반 게임으로 바꾸면 같은 최고 GPU가 나와 원인을 분리했다.

앞선 평가는 예산·합계·호환성·최소 사양 위반을 검사했지만 불필요한 최상급 선택을 독립 조건으로 검사하지 못했다. 이제 기본 무예산 과잉 GPU와 인기 1위 최상급, 가격 확인 실패 후 자동 승급을 회귀 검사한다.

## 수정 정책
- 예산 미지정/단순 무제한: 고객 용도·해상도 및 명시 모델/VRAM 등 조건을 먼저 충족하는 적정 후보를 비교한다.
- GPU 여유 범위는 기존 해상도/용도 참조 지수의 1.5배 이내. 특정 GPU/VRAM을 직접 요구하거나 참조가 없는 경우 해당 요청을 충족하는 후보의 기준을 사용한다.
- 적정 GPU 범위 안의 최저 호환 구성 가격 대비 1.5배 이내에서 세 안을 고른다. 고객 예산을 새로 만들거나 200만원 등 고정 상한을 숨기지 않는다. 발행 상한은 None 유지.
- 기존 인기 60% 가중치는 적정 범위 안에 적용한다. 인기만으로 범위를 벗어난 최상급을 끌어오지 않는다.
- “최고 성능/성능 우선” 명시 시 기존 최대 성능 탐색 유지. “최고 성능은 필요 없다”는 기본 모드. 5090 직접 지정·AI VRAM 32GB 등 실질 고사양 요구도 유지.
- 적정 후보 가격 확인 실패/제외 시 참조 지수를 낮추거나 최고 후보로 승급하지 않고, 적정 유효 후보 확보 필요를 안내한다.
- Python 실서비스와 JS 데모 모두 수정. 무예산 안내 문구도 목적 적합 모드에 맞게 수정. 오버워치/Overwatch를 게임 용도로 명시 판별한다.

배율은 애플리케이션의 비용/성능 여유 정책이며 실제 게임 FPS에 대한 측정값이나 보장치가 아니다. 기존 유한 예산 배분 정책은 변경하지 않았다.
